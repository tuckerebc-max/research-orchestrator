# Evidence and output contracts

## Evidence protocol

For each material claim, capture enough context to judge whether the evidence applies:

- claim supported;
- source title and URL;
- publication or effective date;
- primary, secondary, or tertiary evidence type;
- relevant jurisdiction, population, organization, or time period;
- important methodological or interpretive limitation.

Use primary evidence for consequential claims whenever available. Multiple articles repeating one press release count as one underlying evidence chain, not independent corroboration. When sources disagree, name the positions, compare their evidence quality and applicability, and avoid averaging them into false consensus.

Search-result snippets are discovery aids, not sufficient support for a material claim. Open the source. Quote sparingly and preserve the source's meaning.

Track research effort only when useful. If reporting counts, define them separately:

- **Search operations:** queries or database calls issued.
- **Sources inspected:** distinct underlying documents opened and evaluated.
- **Sources cited:** distinct documents supporting the final output.

Do not assume a numerical ordering among these counts; one search can return many sources and one source can require several retrieval operations.

## Stop conditions

Stop searching when the requested scope is satisfied and one of these holds:

- each material subquestion has adequate support for the decision risk;
- recent searches yield no materially new evidence;
- the agreed time or source budget is exhausted;
- access or tool failures prevent meaningful progress; or
- the user asks to stop.

State which condition ended the search when it affects confidence.

## Output contracts

### Concise answer

Use for bounded questions:

1. Direct answer.
2. Two to five supported findings.
3. Material caveat or uncertainty.
4. Linked citations near the claims they support.

### Research brief

Use by default for multi-part general research:

1. Question, scope, and as-of date.
2. Executive answer.
3. Findings organized by decision-relevant subquestion.
4. Disagreement, uncertainty, and evidence gaps.
5. Implications for the user's decision, clearly labeled as analysis.
6. Sources linked near claims; add a compact source list only when it improves reuse.
7. Optional method note with search operations, sources inspected, sources cited, and access failures.

### Decision-grade brief

Use for consequential educational or governance decisions:

1. Decision and affected groups.
2. Evidence summary and strength.
3. Measurement or inference limits.
4. Benefits, burdens, error costs, and distributional consequences.
5. Alternatives and credible counterarguments.
6. Unknowns and verification needs.
7. Reversible next actions and decision checkpoints.

### Structured research package

Create only when requested or required by the selected specialist. Use stable filenames and include:

- a scope or research-contract file;
- source-backed structured data when applicable;
- a narrative synthesis;
- an exception or unresolved-items list; and
- a concise resume note for continuation.

Do not create a hidden audit trail. Place reusable artifacts in the user-approved workspace and link them in the final response.
